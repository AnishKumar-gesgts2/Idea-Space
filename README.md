## Current focus

The latest handoff investigates how microscopic photonic noise can be reduced to scalable quantum-error-correction models without losing the logical behavior that matters. The current leading direction is a bounded, falsifiable model-reduction study using Strawberry Fields, Stim, and PyMatching.

Start with the [latest research handoff](./Photonic%20QEC%20Research%20Ideation%20%E2%80%94%20Model%20Handoff%20Protocol%20%28Unedited%29.md), then use its numbered sections to move through the historical ideas, active candidates, literature boundaries, rankings, and implementation protocol.
