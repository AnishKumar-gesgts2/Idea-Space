## What is in the handoff?

The handoff is a cumulative research notebook. It preserves earlier ideas and appends later literature reviews, criticism, candidate projects, rankings, implementation protocols, and unresolved questions.

The current active direction studies the reduction

$$
\text{microscopic photonic physics}
\longrightarrow
\text{effective QEC noise}
\longrightarrow
\text{logical failure rate}.
$$

The intended framework division is:

| Framework | Role |
| --- | --- |
| Strawberry Fields | Microscopic photonic states, loss, interference, and detector statistics |
| Stim | High-volume stabilizer and repeated-syndrome simulation |
| PyMatching | Scalable decoding and logical-error estimation |
| PennyLane | Optional optimization only when differentiation answers a scientific question |
